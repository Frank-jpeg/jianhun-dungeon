# 剑魂地下城

横版 2.5D 清屋肉鸽。**单文件 HTML，零依赖，打开即玩。**

👉 **[点这里直接玩](https://frank-jpeg.github.io/jianhun-dungeon/)**

---

## 玩法

每间房清光敌人 → **三选一** 拿强化 → 进下一间。7 间一层，第 7 间是 Boss，打过进下一层，敌人属性递增。

**没有通关终点 —— 层数无限**，敌人一路变强，死了重开。比的是能打到第几层。

核心是 **平A 撑起大部分输出**，技能冷却长，只在起手、位移、清场、救命时用。

## 84 张强化卡

设计上借鉴了三个游戏的思路：

- **哈迪斯** —— 强化不是堆数值，而是**给平A 挂状态**，状态之间有连锁。燃烧、冰霜（叠满 6 层直接冻结）、流血（只在敌人移动时生效）、中毒（削弱敌人攻击）、厄运（延迟 1.2 秒一次性爆发）、连锁闪电。还有**组合卡**：拿齐两张特定元素卡才会出现金色的「炽烈风暴 / 绝对零度 / 血债血偿」
- **死亡细胞** —— **专吃状态的增伤词条**（对燃烧中目标 +32%、对流血中 +30%、对冻结中 +45%），以及条件触发：满血增伤、残血增伤、受伤后复仇、奔跑中势能、空中优势、击杀爆炸、连杀回血
- **霓虹深渊** —— **弹道修饰可叠加**：散射（多射 2 发）、弹射（打完拐向下一个）、追踪、巨弹、贯穿强化（每穿透一个伤害递增）

还借了这几个没做进第一版的机制：

- **雅典娜偏转** —— 闪避的无敌帧内碰到敌方子弹会**反弹回去**，按你的攻击力结算
- **阿佛洛狄忒魅惑** —— 敌人转头打自己的同伴
- **波塞冬撞墙** —— 把敌人击退撞到地图边界，额外伤害并掀翻
- **影子袖剑背击** —— 背后攻击增伤，跟盾卫的绕后机制叠加收益极高
- **赫尔墨斯冲刺充能** 与 **小飞帽二段跳** —— 闪避次数 +1、跳跃段数 +1
- **死亡细胞·谋划** —— 放技能后下一次平A ×2.6，逼你穿插技能而不是一直按 X
- **杀戮天性** —— 击杀减技能冷却
- **濒死活力** —— 致命伤害时锁血不死，6 秒内击杀 3 个敌人就能翻盘复活
- **子弹皇冠** —— 本房间内每击杀 3 个敌人，每次多射一发子弹 / 剑气，进下一间清零
- **腐化** —— 拾取血球后 5 秒内大幅增伤

**传奇卡**：每打过一个 Boss，三选一**整排都是橙色传奇卡**（万雷之主 / 永冬 / 无双连斩 / 不灭之躯 / 死神收割），直接改变构筑上限。共 5 张且都唯一，拿光后恢复普通三选一。

另有环绕剑、战魂随从、守护结界、荆棘之甲、幻影步，以及 5 张诅咒卡（大幅增强 + 明确代价）。

## 操作

| 键 | 作用 |
|---|---|
| `↑ ↓ ← →` | 移动。**上下改变纵深** —— 绕到盾卫背后、躲开弓手的直线弹道 |
| 双击 `←` `→` | 奔跑，移速 ×1.75 |
| `X` | **平A** 连击，主输出，按住自动连 |
| `C` | 跳跃。跳起可躲地面攻击；空中按 `X` 出空中斩 |
| `Z` `S` `D` `F` | 四个技能（`Z` 也可按 `A`） |
| `空格` | 闪避冲刺，位移期间无敌 |
| `1` `2` `3` | 清屋后选卡 |
| `Esc` | 暂停菜单（技能说明 / 属性 / 音量） |
| `M` | 静音 |

左下角技能栏最右边是**闪避格**，蓝色发光=能用，变暗+数字=还在充能。右下角是已获得的强化，平时压暗只露最近 10 张，**鼠标移上去会展开并显示每张的完整效果**。

## 手机 / 平板

**横屏打开同一个网址即可**，会自动切到触摸操作（照 DNF 手游布局做的）：

- **左半屏任意位置按下** 就是摇杆，浮动生成，不用去够固定位置
- **摇杆推到底 = 奔跑**，手机上不需要双击
- **右下大圆键**是平A，按住自动连
- **围在它左上方的四个圆键**是技能，带冷却扇形
- 左边两个小键是 **跳** 和 **闪**
- 血条右边的 `❚❚` 是暂停；暂停面板里可以开全屏、调音量、手动开关触摸操作

竖屏会提示转横屏。

## 两个职业

**鬼剑士** — 近战高爆发。生命 130，贴身输出，靠硬直和浮空把敌人锁在原地。上手最简单。

**神枪手** — 远程走位。生命 106、单发更低但攻速更快、移速更高。隔着半个屏幕输出，被贴脸很难受，靠后跳散弹和走位拉开。子弹一样会被盾卫挡下，照样得绕后。

## 敌人

| 兵种 | 威胁方式 | 应对 |
|---|---|---|
| 哥布林 | 贴身挥砍 | 打断它的起手 |
| 冲锋兵 | 蓄力后直线冲撞 | 侧向走位，或用重击打断 |
| 弓手 | 沿直线平射，射前 0.55 秒画红线 | **上下走一步就躲开** |
| 盾卫 | **常驻霸体**（轻击打不动），正面减伤 80%，远距离举盾冲锋 | 抓它**转身那 0.55 秒**和冲锋后摇 |
| 术士 | 在你脚下种延时爆炸圈 | 别站着不动 |
| 爆弹鬼 | 冲过来自爆，引信 0.85 秒 | **炸之前杀掉**；它也会炸到同伴 |
| 魔蝠 | 高速盘旋后俯冲，打硬直会掉地 | 上挑 / 浮空弹 / 空中斩 |
| 狂战士 | 血厚韧性高，半血后暴怒三连击 | 别站在正面硬吃 |
| 巨魔王 | 横扫 / 跳砸 / 召唤 | 靠纵深躲直线技能 |

**精英怪**（金环）更肉更痛、韧性更高，必掉两颗血球。

## 房间类型

- **普通房** — 2～3 波常规敌人
- **精英房** — 怪少而强，2～3 只精英
- **围攻房** — 不等你清完就放下一波，压力连绵，别贪刀

## 几个设计点

- **硬直分级 + 韧性** —— 轻击 0.22 秒、重斩 0.45 秒、终结斩 0.62 秒，重击直接打断敌人起手。但**连续挨打时硬直会逐次递减**，累计满韧性后敌人会金光一闪进入**霸体反击**，不再吃硬直并立刻还手 —— 所以按住平A 站桩锁死是不成立的，你得穿插走位。Boss 全程霸体，硬直只吃 28%
- **纵深轴是有用的** —— 盾卫正面减伤 78% 且转身有 1.3 秒延迟；弓手只沿 X 轴平射并有 0.55 秒瞄准预警，上下走一步就能躲
- **下一间房的敌人词条会提前预告** —— 护盾 / 分裂 / 疾行 / 狂暴 / 再生，让选卡变成针对性决策
- **音效全部是 Web Audio 实时合成的**，没有任何音频文件

## 技术

原生 JS + Canvas 2D，无框架、无构建、无外部资源。整个游戏就是一个 `index.html`。

坐标系是 `x` 横向 / `y` 纵深 / `z` 离地高度，投影为 `屏幕x = x - 镜头x`、`屏幕y = y - z`，按 `y` 排序绘制 —— 这是横版格斗游戏的经典做法。

数值都在文件顶部的表里（`COMBO_SWORD`、`COMBO_GUN`、`SKILLS_*`、`ET`、`CARDS`），想改手感直接改那几行。
