# 剑魂地下城

横版 2.5D 清屋肉鸽。**单文件 HTML，零依赖，打开即玩。**

👉 **[点这里直接玩](https://frank-jpeg.github.io/jianhun-dungeon/)**

---

## 玩法

每间房清光敌人 → **三选一** 拿强化 → 进下一间。10 间一层，第 10 间是 Boss，打过进下一层，敌人属性递增，无限层。死了重开。

核心是 **平A 撑起约 80% 的输出**，技能冷却长，只在起手、位移、清场、救命时用。26 张强化卡里有 12 张专门堆平A，能滚出雪球。

## 操作

| 键 | 作用 |
|---|---|
| `↑ ↓ ← →` | 移动。**上下改变纵深** —— 绕到盾卫背后、躲开弓手的直线弹道 |
| 双击 `←` `→` | 奔跑，移速 ×1.75 |
| `X` | **平A** 连击，主输出，按住自动连 |
| `C` | 跳跃。跳起可躲地面攻击；空中按 `X` 出空中斩 |
| `Z` `S` `D` `F` | 四个技能（`Z` 也可按 `A`） |
| `空格` | 闪避冲刺，位移期间无敌 |
| `1` `2` `3` | 清屋后选卡 |
| `Esc` | 暂停菜单（技能说明 / 属性 / 音量） |
| `M` | 静音 |

## 手机 / 平板

**横屏打开同一个网址即可**，会自动切到触摸操作（照 DNF 手游布局做的）：

- **左半屏任意位置按下** 就是摇杆，浮动生成，不用去够固定位置
- **摇杆推到底 = 奔跑**，手机上不需要双击
- **右下大圆键**是平A，按住自动连
- **围在它左上方的四个圆键**是技能，带冷却扇形
- 左边两个小键是 **跳** 和 **闪**
- 血条右边的 `❚❚` 是暂停；暂停面板里可以开全屏、调音量、手动开关触摸操作

竖屏会提示转横屏。

## 两个职业

**鬼剑士** — 近战高爆发。生命 130，贴身输出，靠硬直和浮空把敌人锁在原地。上手最简单。

**神枪手** — 远程走位。生命 106、单发更低但攻速更快、移速更高。隔着半个屏幕输出，被贴脸很难受，靠后跳散弹和走位拉开。子弹一样会被盾卫挡下，照样得绕后。

## 几个设计点

- **硬直分级** —— 轻击 0.22 秒、重斩 0.45 秒、终结斩 0.62 秒，重击直接打断敌人起手动作。Boss 有霸体，硬直只吃 28%
- **纵深轴是有用的** —— 盾卫正面减伤 78% 且转身有 1.3 秒延迟；弓手只沿 X 轴平射并有 0.55 秒瞄准预警，上下走一步就能躲
- **下一间房的敌人词条会提前预告** —— 护盾 / 分裂 / 疾行 / 狂暴 / 再生，让选卡变成针对性决策
- **音效全部是 Web Audio 实时合成的**，没有任何音频文件

## 技术

原生 JS + Canvas 2D，无框架、无构建、无外部资源。整个游戏就是一个 `index.html`。

坐标系是 `x` 横向 / `y` 纵深 / `z` 离地高度，投影为 `屏幕x = x - 镜头x`、`屏幕y = y - z`，按 `y` 排序绘制 —— 这是横版格斗游戏的经典做法。

数值都在文件顶部的表里（`COMBO_SWORD`、`COMBO_GUN`、`SKILLS_*`、`ET`、`CARDS`），想改手感直接改那几行。
